# Gunakan URL logo IPB resmi pada header

- ID: 2026-09-official-ipb-logo-url
- Status: Completed
- Prioritas: Normal
- Pemilik: Codex
- Klasifikasi: Routine, pembaruan aset visual bersama.

## Tujuan
Pakai URL PNG resmi IPB yang ditentukan pengguna, sambil menampilkan lambang dengan ukuran yang sesuai di sebelah nama dashboard.

## Penerimaan
- Keempat halaman memuat gambar dari URL resmi yang diminta.
- Gambar dipotong secara visual menjadi lambang ringkas, tanpa mengubah sumber aslinya.
- Tautan menuju situs IPB tetap aman dan aksesibel.
- Uji modul, build, browser, dan deployment berhasil.
- Tidak ada aset logo duplikat yang tidak dipakai.

## Hasil
- URL PNG resmi dipakai bersama pada header empat halaman.
- Build bersih menghasilkan 33 berkas; 12 uji modul lulus.
- Logo terlihat pada desktop dan lebar ponsel 390 px.
- Perubahan dirilis sebagai v1.0.2. Gambar memerlukan koneksi ke server IPB.
