# Audit antarmuka desktop dan ponsel

Tanggal: 2026-09-28
Task: perapian tema Dashboard Tesis

## Perubahan
- Merek header dan judul situs menjadi Dashboard Tesis.
- Tema biru-putih datar menggantikan ungu dan gradasi. Tema terang menjadi awal; tema gelap dapat dipilih dan disimpan.
- Tombol mendapat gerak singkat saat hover dan tekan. Pengaturan reduced motion mematikan transisi.
- Desktop memakai navigasi atas. Lebar sampai 600 px memakai empat tab tetap di bawah.
- Beranda, analisis, metode, dan peta menyesuaikan layar kecil. Tabel metode memakai wadah geser.
- Peta mempertahankan basemap gelap, legenda, kontrol zoom, dan atribusi OpenStreetMap.
- Jalur halaman dan aset tetap relatif untuk GitHub Pages di subfolder.

## Audit bertahap
1. Beranda diuji pada lebar 1440 px dan 390 px. Grafik tren, perubahan rata-rata, peringkat wilayah, dan Moran termuat. Moran kemiskinan 2025 tampil I=0,6002, p=0,001, 999 permutasi.
2. Peta diuji pada kedua lebar. Geometri 154 wilayah, legenda kuartil, zoom, pencarian peubah, pilihan tahun, dan atribusi OSM tersedia. Filter Gini dan tahun 2020 mengubah peta dan URL.
3. Analisis diuji pada kedua lebar. Tab spasial menampilkan Moran dan LISA, tab temporal menampilkan grafik tren, dan tab gabungan menampilkan seri Moran tahunan. Pergantian tab bekerja.
4. Metode diuji pada kedua lebar. Tab konsep bekerja dan kamus memuat 18 peubah. Pada 390 px tabel bergulir di wadahnya tanpa memperlebar halaman.
5. Tema gelap aktif melalui tombol, label tombol berubah, dan pilihan tersimpan. Tema kemudian dikembalikan ke terang.

## Hasil pemeriksaan
- node uji-node.mjs: 12/12 lulus.
- node --check pada modul aset/*.js: lulus.
- python build_site.py: sukses, artifact _site berisi 30 file.
- Keempat halaman termuat di browser tanpa elemen berstatus memuat. Tidak ada error runtime setelah blok deklarasi ganda di pemilih tahun beranda diperbaiki.
- Viewport 1440 px dan 390 px tidak menimbulkan overflow horizontal. Tabel tetap di dalam wadah geser pada ponsel.
- Navigasi aktif sesuai halaman di desktop dan ponsel.

## Batas audit
Layar 390 px diuji memakai viewport browser desktop. Ini memeriksa breakpoint ponsel, tetapi belum menggantikan uji sentuh pada perangkat Android atau iPhone fisik. Basemap memerlukan koneksi internet.

Status: kriteria tampilan, runtime, responsivitas, dan build selesai.
