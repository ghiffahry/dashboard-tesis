# ADR 0011: Laman Draft berfokus pada dokumen

- Status: Diterima, 2026-10-14.

Pembaca PDF menjadi elemen utama setelah header sederhana. Ringkasan diringkas menjadi tiga kartu di bawah dokumen: metadata PDF, cakupan penelitian, dan model utama. Ini menghindari grid analisis di halaman formal dokumen dan menjaga pembaca terlihat penuh pada desktop serta ponsel.
