# Data geometri sumber lokal

Letakkan berkas shapefile wilayah Sumatera (`sumatera.shp`, `.shx`, `.dbf`, `.prj`, dan `.cpg`) di folder ini sebelum menjalankan pipeline `build.ps1`. Berkas sumber tidak dilacak Git dan tidak diterbitkan. GeoJSON hasil olah yang dipakai situs berada satu tingkat di atas folder ini.
